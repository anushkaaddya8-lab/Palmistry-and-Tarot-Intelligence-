# Palmistry and Tarot Intelligence

## Project Overview
Palmistry and Tarot Intelligence is an AI-powered web application that provides palm reading and tarot card predictions using Artificial Intelligence.

## Features
- User Registration & Login
- Palm Image Upload
- AI Palm Analysis
- Tarot Card Reading
- Personality Insights
- Life Trend Prediction
- Prediction History
- PDF Report Generation

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Google Gemini AI
- MediaPipe
